# Bog Cloud product direction

Bog Cloud is an agent-first infrastructure prototype. Prioritize useful HTTP APIs, MCP tools/resources, WebMCP where appropriate, and machine-readable documentation. Agents are the primary intended consumers.

Do not add or prioritize a dedicated visual dashboard unless the user explicitly requests one. Design observability and administration as programmatic contracts first; existing human sign-in, approval, and private-download controls remain useful supporting flows.

Keep prototype work bounded: preserve existing data and permissions, verify actual behavior, and distinguish implemented features from tests or external checks still pending. Do not expand paid infrastructure without authorization.
