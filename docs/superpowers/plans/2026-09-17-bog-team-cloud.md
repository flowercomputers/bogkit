App credentials cannot provision/mint/invite. Owners manage membership and Bog deletion. Removal revokes issued workspace app credentials. Accounts keyed by verified issuer+subject, never email. Bog owns permissions; provider owns OAuth. No replacement custom authorization server. Browser and MCP auth-code/PKCE; HTTP-only device flow. Issuer/audience/signature/expiry verified. Local suspension/membership checked on every use. Credentials stay out of chat/logs/URLs.
Three Bogs/workspace,16MiB logical JSON/Bog,32 retained globally,8 resident,2 starts,10min idle. Grandfather oversize stores read/shrink only; atomic mutations enforce growth bounds. No auto paid expansion. Single host until measured capacity passes. Existing IDs/data/scoped credentials preserved in legacy workspace claimed only by explicitly verified operator provider identity. Scoped migration of existing chat and exposed-owner rotation before public cutover, then global-owner public access disabled, private admin retained.
Invitations single-use/revocable/seven days, GitHub acceptance. Console for ownership/membership. REST/MCP share operations. Publish templates/discovery/OpenAPI/llms/auth docs from shared contract; default records-v1; aggregate actionable missing creation requirements. Explicit workspace parameters default personal, never browser-selected ambient workspace. Owner-confirmed deletion revokes access before retryable file cleanup.
Daily encrypted off-host S3-compatible backups,7-day retention,restore drill,auth/provision/restart/disk/backup observability. Real fresh-agent MCP and HTTP/device tests with second-account isolation, migration/recovery, zero credential leaks before publish.
Later changes: opaque generation-aware cursor,seq preserved,25s max authenticated long-poll+MCP,recheck authorization,bounded waiters,explicit reset after restart/restore,document actual view ordering. No durable change history claim.
