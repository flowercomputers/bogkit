Your Bogs

App access

Give a server-side application a credential for one Bog. Prepare access, then explicitly download a private configuration file. Keep it in your application's secret store; never paste it into a conversation.

The file contains a credential. Move it to a private location, restrict its permissions, and keep it out of source control.

Agent access
Named credentials last 30 days and work in your current workspaces. Agents can create Bogs and issue app credentials, but cannot manage members, delete Bogs, or create account credentials.
People
Members can create Bogs, use shared data, and issue app credentials. Owners also manage invitations, membership, and deletion.
Create an organization
A shared workspace keeps your team's Bogs separate from your personal projects. Invite people through the People section after creating it.
Platform allowances
Only platform operators see these controls. An account flag uncaps its personal workspace. An organization flag uncaps that workspace for all members. Host capacity and the 16 MiB per-Bog storage limit still apply. Removing a flag preserves existing Bogs but prevents creation above the normal allowance.
