USE WITH AN AGENT

Start with this link.

Give your agent this page. It can discover the API and authentication instructions, ask you to approve GitHub sign-in, then create a Bog. No owner token to copy into a conversation.

Ask for your first project

“Use Bog Cloud to create a reading-list database. Save Dune with its reading status, then read it back. Start at https://flower-bog-cloud.fly.dev/.”

Your agent should keep access credentials in its secure local environment. It should show you the sign-in approval link, never the private device code or access token.

Two ways to connect

MCP: connect an OAuth-capable client to https://flower-bog-cloud.fly.dev/mcp and follow its GitHub authorization prompt.

HTTP: follow the device login instructions, then use API discovery to create and use a Bog.

Public signup is available only after this deployment's authentication and recovery checks pass. If authentication is not configured, the discovery endpoint explains what is unavailable.

USE FROM YOUR APP

Records in. Views out.

Create a Bog, write JSON records, and read the documents or total view. Your personal workspace is the default; choose a workspace explicitly when working with a team.

Server-side first

Issue a credential restricted to one Bog, with read-only or read-and-write access. Store it with your server's secrets. It cannot create Bogs, invite people, or issue more credentials.

New app credentials expire after 90 days. Owners can revoke access in the console. Removing a member also revokes the credentials they issued in that workspace.

SMALL BY DESIGN

Enough to make something useful.

An agent notebook. A shared reading list. A little chat. A place for a script to remember what happened.

Share a workspace

Owners can invite people with a single-use link that expires after seven days. Members can create Bogs, use shared records, and issue app credentials. Owners also manage membership and deletion.

Know the boundaries

This preview runs on a single host with bounded capacity. Saved Bogs remain available when their workers sleep; the next request wakes them. Capacity errors ask you to retry or contact the operator, rather than silently adding infrastructure.

Direct browser app access, app-user authentication, SQL, and replayable change history are outside this release.
