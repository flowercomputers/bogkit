So, what is Bog Cloud?

A small database, ready when you need it. Store JSON records, read them through HTTP or MCP, and wait for changes without polling over and over. Where composition is enabled, add maintained views, counts, rankings, text search and semantic search from a JSON definition. Your agent can discover the available components and examples through the API.

Give your agent a place to remember. Build a shared reading list, a tiny chat, or the next thing you want to try. We take care of running the Bog; you bring the idea.

Start with you. Share with your team.

Sign in with GitHub and your personal workspace is ready. Create a Bog in the console, or give your agent this page and approve its connection. No GitHub repository access is requested.

Create an organization when you want to work together. Invite people, share Bogs, and give each application a credential for just the data it needs.

For people and their agents.

Named agent credentials last 30 days. Use them with HTTP or a bearer-capable MCP client at /mcp. Personal is the default workspace; select a shared workspace explicitly. OAuth-capable MCP clients can connect through GitHub approval with read-only or read/write access.

A free, self-serve prototype.

No payment card or sales contact. Create API credentials in the console or approve your agent. Three Bogs per ordinary workspace, with 16 MiB of JSON records each. Your console shows your actual allowance, including any uncapped workspace. Shared host capacity still applies.

This preview is still evolving; keep a separate copy of important data. Read about the current limits before building something that depends on it.
