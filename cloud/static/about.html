Bog Cloud is a working prototype from Flower Computer. It puts a small hosted Bog behind an HTTP API and MCP endpoint, so a person or their agent can create a place to keep JSON records without first setting up a database server.

The current service is suited to experiments such as a shared reading list, a tiny chat, an agent notebook, or state for a personal script. GitHub sign-in identifies people without requesting repository access. Personal workspaces keep independent accounts separate; organizations let invited people share access.

This is an early, free service with bounded storage and shared host capacity. It is not a promise of unlimited infrastructure or production durability. Keep a separate copy of important records. For the supported operations, actual limits, and examples, read the Bog Cloud documentation. For the wider Bog toolkit and company, visit Flower Computer.
